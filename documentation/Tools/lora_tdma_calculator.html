Interpretation

    Model scope

    Tsymbol = 2^SF / bandwidth. Time-on-air uses the SX1276 explicit/implicit-header LoRa packet formula, with the configured RadioHead header bytes included in PHY payload length. Nominal bit rate is SF × bandwidth / 2^SF × 4/(4+CR).

    Capacity includes the main and secondary per-node packets multiplied by expected attempts. It does not automatically include base `ACK_SUMMARY`, `TIME_SYNC`, commands, joins, window markers, external interference, turnaround time, or legal channel-use constraints. The equal-slot bound includes guards and the utilization ceiling; the airtime-only bound ignores TDMA structure; the one-packet/slot bound is deliberately conservative.
